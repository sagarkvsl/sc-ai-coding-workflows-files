# Task: fix four reported problems

Users of the Task Board reported these problems. There are no error messages and no failing tests. Find each cause in the code and fix it.

1. "I add a task and it appears in the **In progress** column. New tasks should start in **To do**."
2. "New tasks show up at the **bottom** of their column. The newest task should be at the **top**."
3. "When I search for a word that is only in a task's **description**, nothing is found. Search should match the title or the description."
4. "After I add a task with the keyboard, my cursor is lost. It should go back to the **Title** field so I can type the next one."

Each problem has its own cause, and they are in different parts of the code. Fix the causes, do not work around them in the interface, and do not change behaviour that works.
